# 商业营运学习笔记

> 整理人：本人（计算机背景，假期自学商业营运）  
> 说明：以下内容是我面试商业营运岗位前，结合项目实践和公开资料整理的学习笔记。很多地方可能理解不深，主要想展示学习态度和思考过程。

---

## 一、商业地产营运到底是什么

以前我的理解是"收租"。最近看了一些资料后才明白，**商业营运的核心是"让场子旺起来"**，让商户赚钱、让消费者愿意来，最终实现租金和资产价值的双提升。

简单拆成三块：

1. **招商**：把合适的品牌招进场，定位置、定面积、定租金。
2. **营运**：日常管理商户，帮商户做销售、分析经营问题、调整陈列和活动。
3. **推广**：引流、会员、活动策划，把客流搞起来。

这三块互相影响。招商没招好，后面营运很累；营运数据不好，招商调改也没方向。

## 二、商场营运常见指标

### 1. 销售相关

| 指标 | 含义 | 为什么重要 |
|---|---|---|
| **销售额 / Sales** | 商户在一定时间内的成交金额 | 最直接的经营结果，决定租金和提成 |
| **坪效** | 销售额 ÷ 经营面积 | 衡量单位面积的产出效率，不同业态差异很大 |
| **同店同比增长** | 同一家店今年同期比去年增长多少 | 剔除新店影响，看真实经营趋势 |
| **客单价** | 销售额 ÷ 交易笔数 | 反映顾客消费能力 |
| **提袋率 / 转化率** | 成交笔数 ÷ 进店客流 | 看导购和货品匹配度 |

### 2. 租金相关

- **固定租金**：每月固定交一笔钱，旱涝保收但和经营风险割裂。
- **扣点租金**：按销售额的一定比例抽成，风险共担。
- **保底 + 扣点**：两者取高，比较常见。
- **租售比 / 租金占销比**：租金 ÷ 销售额。一般餐饮业希望控制在 10%–15%，零售可能更高一些。超过合理区间，商户容易亏损。

### 3. 客流相关

- **客流量 / Footfall**：进入商场的人数。
- **车流 / 地铁接驳**：影响客流的来源结构。
- **停留时长**：在商场待多久，影响消费机会。
- **会员数 / 会员消费占比**：反映私域运营能力。

### 4. 经营健康度

- **出租率 /  occupancy rate**：已租面积 ÷ 总可租面积。低于 90% 通常说明招商或运营有问题。
- **掉铺率 / 闭店率**：一段时间内关店的比例，侧面反映经营压力。
- **坪效排名 / 业态占比**：用于判断要不要调整品牌组合。

## 三、业态组合与定位

商场不是把品牌随便塞进去就行，要考虑**业态配比**。

- **引流业态**：影院、超市、快餐饮、主力店。利润薄，但能带人流。
- **利润业态**：零售、黄金珠宝、美妆。租金承受能力强。
- **体验业态**：亲子、娱乐、健身。能增加停留时间。

不同定位的商场配比完全不同：

- 社区型商场：超市、亲子、餐饮占比高。
- 区域型购物中心：时尚零售、餐饮、娱乐更均衡。
- 城市级高端商场：奢侈品、美妆、高端餐饮为主。

学习中我发现，**客流和销售是表象，业态组合和租金结构才是背后的杠杆**。

## 四、商户经营分析常用思路

### 1. 看绝对值不如看相对值

销售额高不一定好，要看坪效、租售比、同比趋势。比如一家店月销 50 万，但面积 300㎡，坪效可能还不如月销 20 万但面积 80㎡ 的小店。

### 2. 和同类比

同一品类、同楼层、同商圈的店做横向对比。比如咖啡品类在商场 A 的坪效 vs 商场 B 的坪效，能看出品牌和位置的匹配度。

### 3. 看趋势而不是单点

连续三个月下滑比单月波动更危险。需要结合节假日、活动、天气、竞品开店等因素一起看。

### 4. 找异常

- 客流高但销售低：可能是货品不对、价格带错、导购能力弱。
- 客流低但销售高：可能是品牌忠诚度高，但流量瓶颈明显。
- 租售比过高：预警撤柜风险。

## 五、营运和数据的结合点

因为我是计算机背景，所以对数据这块比较敏感。学习中我整理了几个可以直接用数据驱动营运决策的点：

1. **品牌热度监测**：看大众点评、小红书等平台的讨论量、评分、差评关键词，提前发现经营风险。
2. **竞品对比**：同一品类在不同商场的门店数和口碑，判断品牌扩张方向。
3. **招商辅助**：通过外部数据判断一个品牌在本城市、本商圈的受欢迎程度，降低招商试错成本。
4. **活动效果评估**：活动前后客流、销售、会员转化的变化。

我目前的项目 BrandPulse 就是在做这件事：把大众点评、小红书的公开数据抓下来，计算口碑分、热度指数、声量份额，最后落到看板和对话助手里。技术上用了爬虫、指标管道、Agent 工具、前端可视化；业务上其实是在回答"这个品牌能不能招""这家店经营得怎么样""同品类谁更有竞争力"这些问题。

## 六、一些还不大懂、准备继续学的

1. **租金谈判细节**：保底、递增、装补、免租期、物业管理费怎么平衡？
2. **财务报表阅读**：商场的 NOI、EBITDA、资本化率怎么算？
3. **不同城市级别/商圈的业态差异**：一线和二三线城市的消费结构差别。
4. **品牌运营能力评估**：除了销售额，还有哪些软性指标能判断一个品牌是否值得招？
5. **合同法务和运营SOP**：实际落地中有很多流程和规范要学习。

---

## 七、总结

假期这段时间，我从"完全不懂商业营运"到"能看懂基本指标、能把数据和营运问题对应起来"，主要靠两块：

- 一是阅读公开资料、案例和行业报告；
- 二是通过 BrandPulse 项目实际动手，把爬虫、指标计算、前端看板串起来，反向逼着我去理解这些指标的商业含义。

我清楚自己离真正做营运还差很远，但至少已经建立起了一个基础框架：**用客流、销售、租金、坪效、租售比、同比趋势等指标去观察一个商场的健康状况，再用外部舆情数据辅助招商和调改决策**。后续会继续补财务、法务、谈判和实际现场运营方面的知识。
